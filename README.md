# Raven Kumar — Portfolio

Personal portfolio of Raven Kumar A/L Saravanan, Software Developer Student at Universiti Sultan Zainal Abidin (UniSZA).

## Description

A responsive, single-page portfolio built with HTML5, CSS3, and vanilla JavaScript. Features include dark/light theme toggle, bilingual interface (English/Bahasa Malaysia), and interactive 3D visualizations for project showcases.

## Features

- Hero section with typed roles, social links, and resume download
- About section with profile, education, and skills
- Experience timeline
- Skills organized by category
- Featured projects showcase
- Final Year Project (FYP) case study with 3D smart bin visualization and system architecture diagram
- Robotics competition showcase with 3D Mechabot model
- Blog section
- Contact information
- Dark and Light theme toggle
- Bilingual support (English and Bahasa Malaysia)
- Animated particle background
- Scroll-triggered animations
- Fully responsive design

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, 3D transforms)
- JavaScript (vanilla ES6+)
- Font Awesome 6
- Google Fonts (Space Grotesk, JetBrains Mono)
- Node.js and Express
- GitHub Pages

## How to Run the Project

### With Node.js

```bash
npm install
npm start
```

Then visit `http://localhost:3000`

### Direct

Double-click `index.html` to open in your browser.
